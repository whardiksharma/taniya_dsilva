# Taniya D’silva — Strategic Social Impact Advisory

A dedicated Frappe app powering the executive portfolio website for Taniya D'silva (Wise Impact Consulting Solutions).

## Features
- **Multi-Tenant Host Routing**: Powered by `taniya_dsilva.routing.set_home_page` (same architecture as Bumping Into Bugs) to serve dedicated domains or subdomains.
- **Custom Settings DocType**: Configurable via `Taniya Portfolio Settings` Single DocType.
- **Four Bespoke Design Options**:
  - `01. Obsidian Balmoiabe`: Split slider horizontal panels.
  - `02. Warm Ivory`: Luminous editorial ivory aesthetic.
  - `03. Systems Atlas`: Dark ecological corridor matrix.
  - `04. Asymmetric Editorial Spread`: High-fashion magazine spread with overlapping multi-photo compositions.
- **Direct Lead Routing**: Full 9-point inquiry form routed to `its.taniya.dsilva@gmail.com`.

## Installation
```bash
bench get-app https://github.com/OmmNoMi/Biz_Taniya.git
bench --site <your-site> install-app taniya_dsilva
```
