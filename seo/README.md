# Taniya D’silva — SEO Programme

Internal working files for the monthly SEO programme of **`https://taniyadsilva.com`** (Strategic Social Impact Advisory & Wise Impact Consulting Solutions).

> ⛔ **Not served by the website. Never link to these publicly** — they contain competitive teardowns, executive targeting, client-acquisition funnel metrics, and agency commercial strategy.

The SOP lives at [`.agents/skills/taniya-seo-monthly/SKILL.md`](../.agents/skills/taniya-seo-monthly/SKILL.md) — how to run a monthly cycle, the frozen rules, dependencies, and the Learning Log. Read that first.

## Folder Map

| Path | What it is | Rule |
|---|---|---|
| `METHOD.md` | The frozen method — geo scope, search queries, rank tracking sources, telemetry instruments, cadence. **Version 1.0**. | Don't change without bumping the version and recording in tracker |
| `keywords/keyword-universe-v1.csv` | **65+** keywords across 5 thematic clusters (Personal Brand, Social Impact Advisory, Climate & Agrarian Transition, Gender Equity & Labour, Public Health & Portfolio Leadership). | **Add-only.** Never reword, never delete |
| `reports/taniya-seo-report--YYYY-MM.md` | One report per month. **Markdown only** — client deliverable uploaded to Drive as `TD_SEO-Report_YYYY-MM.docx` (naming convention: SOP §3). | Never edited after sign-off |
| `templates/monthly-report-template.md` | Copy this each cycle | Structure is fixed; content changes |
| `tracker/taniya-tracker.csv` | One row per month, 36 standardized columns (portfolio roll-up compatible with Gaonhae). | Append only |
| `fixes/fix-backlog.md` | Prioritized technical & on-page SEO backlog mapped to `apps/taniya_dsilva` file:line. | Update statuses each cycle |
| `evidence/` | Dated raw captures, GSC exports, CWV / Lighthouse audits. | Never overwritten |
