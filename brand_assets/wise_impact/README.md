# Wise Impact Consulting Solutions — Official Brand Assets

This directory contains the standalone vector (`.svg`), master raster (`.png`), and interactive showcase (`.html`) brand assets for **Wise Impact Consulting Solutions** (Practice of Taniya D’silva).

> **Isolation Note**: This folder is located outside `taniya_dsilva/` and `taniya_dsilva/www/`, ensuring these source design assets remain fully version-controlled without interfering with Frappe desk routes or website rendering.

---

## 🎨 Asset Catalog

| File Name | Format | Description | Primary Use Case |
|---|---|---|---|
| **`wise_impact_circle.svg`** | Scalable Vector (`.svg`) | **Clean Circular Globe Artwork.** Zero yellow/gold outline, zero outer rings, zero text. Clean circular watercolor crop with full bleed (no bottom gap) and 100% transparent exterior. | **Primary circular logo / favicon / profile icon** |
| **`wise_impact_circle_borderless.svg`** | Scalable Vector (`.svg`) | Standalone borderless circular crop of the watercolor globe artwork. | Circular avatar / app icon |
| **`wise_impact_emblem.svg`** | Scalable Vector (`.svg`) | **Circular Emblem / Seal.** Features concentric medallion rings and circular curved typography (*"WISE IMPACT CONSULTING SOLUTIONS"* & *"TRANSFORMING SYSTEMS FOR PEOPLE & PLANET"*). | Formal seals, stamps, official certificates |
| **`wise_impact_banner.svg`** | Scalable Vector (`.svg`) | **Full Horizontal Brand Banner.** Features the central circular artwork lockup paired with typography. | Letterheads, presentation headers, reports |
| **`wise_impact_logo.svg`** | Scalable Vector (`.svg`) | **1:1 Exact Match Vector.** Direct vector rendition of the client's original hand-drawn watercolor globe and people illustration with original background grid. | High-fidelity archive & master vector print |
| **`wise_impact_transparent.svg`** | Scalable Vector (`.svg`) | Vector artwork with background grid removed, leaving pure watercolor artwork and people. | Overlay on colored stationery or presentations |
| **`wise_impact_globe_master.png`** | High-Res PNG | Spherical 3D globe with people distributed across continents (Americas, Europe, Africa, Asia). | Marketing collateral, deck covers |
| **`wise_impact_logo_showcase.html`** | Standalone HTML | Interactive browser showcase with dark/light/sage background tint controls comparing all logo variants. | Client presentation & stakeholder review |
| **`wise_impact_spinning_globe.html`** | Three.js HTML | Interactive 3D spinning globe simulation. | Web animation prototype |
| **`wise_impact_interactive_globe.html`** | Three.js HTML | Interactive 3D globe with draggable orbit controls. | Interactive web concept |
